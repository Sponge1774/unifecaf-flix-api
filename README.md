# unifecaf-flix-api
API REST de filmes da UniFECAF Flix em Node.js (Express) e MySQL, no padrão MVC. Três endpoints de consulta em /v1/controle-filmes, busca FULLTEXT, validação de entradas, documentação OpenAPI (Swagger), testes no Postman e automatizados, e CI no GitHub Actions. Web Programming for Back End.
